# Novaro x YouTube Shopping: Step 3 check-in

Creators who have reached Step 3 ("Get reviewed") in YouTube Studio > Earn use this page to tell Novaro, so we can ask YouTube to fast-track their review.

The page posts to a Google Apps Script web app ("Novaro YouTube Step 3 Check-in", in Joe's Drive). It logs each request to the "Novaro YouTube Step 3 Requests" sheet and, every hour, passes channels signed with Novaro to the YouTube team's sheet.
